# Alijaya NetSuite - Universal GenieACS Mobile & Desktop Suite

Alijaya NetSuite is a multi-vendor TR-069 mobile and desktop management suite for GenieACS servers.

## Features
- **Universal Multi-Vendor TR-069 Support:** Full support for ZTE, Huawei, CIOT, FiberHome, ZICG, RTEG, etc.
- **39 VirtualParameters:** Automatic token-matching and TR-069 vendor fallbacks.
- **Interactive Network Map:** Leaflet-based map with ODP markers, dropcore lines, and live GPS routing.
- **Overview Donut Charts:** 6 real-time network overview charts.
- **Cross-Platform:** Android, Windows Desktop (Portable), Web, and iOS (GitHub Actions CI/CD).
